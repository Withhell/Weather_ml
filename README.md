This project was created as a final project for Machine Learning course in KNEU.

It uses historical weather data from [Open-Meteo](https://open-meteo.com/) that was parsed using Open-Meteo Historical Weather API and Forecast API.

In this project uses Logistic Regression, Decision Tree Classifier, Random Forest and KNN for classification of percipitation probability.



This project contains the following files:
  1. app.py: contains code for Streamlit app that pulls data from Open-Meteo, trains ML models and displays classification matrix for the best model and importance of variables used for training. And in the end makes a percipitation forecast. It is an independent file and should be ran in Bash: 'streamlit run app.py'</p>
  
  2. daily_weather_data.csv: Daily weather in Kyiv from 2025/05/25 to 2026/05/25 pulled from Open-Meteo with such columns as:
      - "temperature_2m_mean": mean air temperature at 2 meters above ground, Celsius; 
      - "precipitation_probability_mean": mean probability of percipitation, %; 
      - "relative_humidity_2m_mean": Relative humidity at 2 meters above ground, %; 
      - "precipitation_sum": Sum of daily precipitation (including rain, showers and snowfall), mm;
      - "surface_pressure_mean": mean surface preassure for the day, hPa; 
      - "visibility_mean": Mean visibility for the day;
      - "dew_point_2m_mean": Dew point temperature at 2 meters above ground, Celsius.

  3. best_weather_model.pkl: saved best model generated by forecast.py

  4. forecast.py: python file that trains ML models using daily_weather_data.csv, finds the best one, saves it as best_weather_model.pkl and uses it to forecast weather using Open-Meteo Forecast API. Should be ran after import_openmeteo_requests.py.

  5. import_openmeteo_requests.py: pulls historical weather data from Open-Meteo using Historical Weather API and saves it as daily_weather_data.csv.
